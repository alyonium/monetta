# Learnings

- i18n: `src/i18n/en.ts` nested catalog, init in `src/i18n/index.ts`, typed keys via `src/i18n/i18next.d.ts`. Use `t()` in helpers/tests and `useTranslation()` in components. Interpolation: `{{name}}`.
- Tests: `npm test` runs `vitest run`. Config is `vitest.config.ts` (`environment: 'node'`, alias `@` → `src`). Do not put tests in `vite.config.ts` (PWA plugin). Shared `localStorage` stub: `src/helpers/tests/stubLocalStorage.ts` (not a `*.test.ts`, so Vitest does not run it).
- Typecheck: `tsconfig.app.json` maps `@/*` via `paths` to `./src/*`. Do not add `baseUrl`.
- Firefly client: do not edit `src/api`. Configure the singleton from `src/helpers/configureApiClient.ts`. Storage keys: `monetta.token`, `monetta.backendUrl`. `normalizeBackendUrl` trims, takes origin, returns `{origin}/api` (`/v1` is added by the SDK). Normalize on write (`setBackendUrl`) and again in `configureApiClient` before `baseUrl`. `setConfig` merges; pass `null` header values to delete. Stub `localStorage` in tests via `vi.stubGlobal`.
- Login: `src/modules/login/Login.tsx` + `Login.module.css`. Route is `ROUTE.LOGIN` (`/monetta/login`). Check credentials with `getCurrentUser`, not `getAbout`. `throwOnError` stays false; try/catch treats HTML/JSON parse and network/CORS as `invalidBackendUrl`. 401/403 → `invalidToken`. Write `localStorage` only after success. Helper tests in `src/modules/login/tests/`; mock `getCurrentUser` from `@/api/sdk.gen.ts`. Logout/clear is US-039.
- Auth shell: `hasAuthCredentials()` in `src/helpers/authStorage.ts` (both keys non-empty after trim). `RequireAuth` lives in `src/components/RequireAuth/`. `AppLayout` is a `100dvh` column + footer in `src/components/AppLayout/` (`AppLayout.tsx` + `AppLayout.module.css`, tabs in `constants.ts`). Routes: `ROUTE.HISTORY` / `ANALYTICS` / `SETTINGS`. Login is outside the layout and does not redirect away if already signed in. Query persist wraps the authenticated tree (`QueryPersistenceProvider`). Budget chrome (US-009) fills `AppLayout` `main`. Shared UI in `src/components/<Name>/` follows the same layout as a module (component + CSS together, `constants`/`helpers`/`hooks`/`types`/`tests` only when needed).
- Query persist: `@tanstack/react-query` + `@tanstack/react-query-persist-client` + `idb-keyval`. Query helpers live in `src/helpers/query/` (`constants.ts`, `createQueryClient.ts`, `createQueryPersister.ts`). Provider `src/components/QueryPersistenceProvider/` wraps only the authenticated tree (`RequireAuth` → provider → `AppLayout`). Login stays outside so it does not write IndexedDB. Storage key `monetta.queryCache` (IndexedDB `keyval-store`). `gcTime` and persist `maxAge` are 90 days; `staleTime` is 1 hour; `retry` is 1. Client is created once via `useState(() => createQueryClient())`. `onSuccess` restore calls `invalidateQueries()` so a cold start refetches Firefly while tab switches keep the mounted provider. Persist writes on cache `added`/`removed`/`updated` only — the key appears after the first query (US-008 / US-014), not on an empty cache. Logout should call `queryClient.clear()` plus `removeClient()` (US-039). Do not add Query to `openapi-ts` / `src/api`.
- Wallet currency: helpers in `src/helpers/currency/` (`types.ts`, `fetchPrimaryCurrency.ts`, `fetchExchangeRates.ts`, `convertToPrimary.ts`). Tests in `src/helpers/tests/`. Use `getPrimaryCurrency`, not `primaryCurrency` (that POST makes a currency primary). `listCurrencyExchangeRates` is paged (`limit` 50); keep latest `date` per `from+to` and uppercase codes. Empty rates is valid. `convertToPrimary` is pure: same code → amount; direct `from→primary`; else reverse `1/rate`; no pair → `null` (no 1:1, no third currency, no rounding). First `useQuery` wrappers are US-014 (totals) and US-008 (accounts).
- Budget accounts: types in `src/modules/budget/types/budgetAccount.ts` (`AccountType` INCOME|CURRENT|EXPENSE, `isDebt`, currency, debt fields). `icon`/`color` are `string | null` — no Wallet/`#4C6EF5` in the model; UI fallback is US-010/US-016. Map Firefly with `Pick<AccountRead, 'id' | 'attributes'>`: revenue→INCOME, asset→CURRENT, expense→EXPENSE, liability/liabilities→EXPENSE+debt; skip `active: false`, empty id/name, other Firefly types. Buckets keyed by `AccountType`; order preference wire key is `type.toLowerCase()` (`monetta.accountOrder.income`). Preferences: paged `listPreference` and PUT `updatePreference`. Appearance is a JSON string; `PolymorphicProperty` is not an object. Do not write appearance while mapping. Extract a shared Firefly page-loop when US-008 adds `listAccount`. US-008 adds `useBudgetAccounts`.
