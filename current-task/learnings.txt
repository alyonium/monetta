# Learnings

- i18n: `src/i18n/en.ts` nested catalog, init in `src/i18n/index.ts`, typed keys via `src/i18n/i18next.d.ts`. One namespace `translation`. Components use `useTranslation()` and full keys (`t('budget.income')`), same as login. Interpolation: `{{name}}`.
- Tests: `npm test` runs `vitest run`. Config is `vitest.config.ts` (`environment: 'node'`, alias `@` → `src`). Do not put tests in `vite.config.ts` (PWA plugin). Shared `localStorage` stub: `src/helpers/tests/stubLocalStorage.ts` (not a `*.test.ts`, so Vitest does not run it). Budget helper tests live in `src/modules/budget/helpers/tests/` (SDK fixtures in `testHelpers.ts`, not `helpers.ts`). Tests that are not helpers sit next to the source (`accountIcons.test.ts`, `pageSwipe.test.ts`). Do not put a `tests/` folder at the module root.
- Typecheck: `tsconfig.app.json` maps `@/*` via `paths` to `./src/*`. Do not add `baseUrl`.
- Firefly client: do not edit `src/api`. Configure the singleton from `src/helpers/configureApiClient.ts`. Storage keys: `monetta.token`, `monetta.backendUrl`. `normalizeBackendUrl` trims, takes origin, returns `{origin}/api` (`/v1` is added by the SDK). Normalize on write (`setBackendUrl`) and again in `configureApiClient` before `baseUrl`. `setConfig` merges; pass `null` header values to delete. Stub `localStorage` in tests via `vi.stubGlobal`.
- Login: `src/modules/login/Login.tsx` + `Login.module.css`. Route is `ROUTE.LOGIN` (`/monetta/login`). Check credentials with `getCurrentUser`, not `getAbout`. `throwOnError` stays false; try/catch treats HTML/JSON parse and network/CORS as `invalidBackendUrl`. 401/403 → `invalidToken`. Write `localStorage` only after success. Helper tests in `src/modules/login/tests/`; mock `getCurrentUser` from `@/api/sdk.gen.ts`. Logout/clear is US-039.
- Auth shell: `hasAuthCredentials()` in `src/helpers/authStorage.ts` (both keys non-empty after trim). `RequireAuth` lives in `src/components/RequireAuth/`. `AppLayout` is a `100dvh` column + footer in `src/components/AppLayout/` (`AppLayout.tsx` + `AppLayout.module.css`, tabs in `constants.ts`). Routes: `ROUTE.HISTORY` / `ANALYTICS` / `SETTINGS`. Login is outside the layout and does not redirect away if already signed in. Query persist wraps the authenticated tree (`RequireAuth` → `QueryPersistenceProvider` → `AppLayout`). Budget chrome (US-009) fills `AppLayout` `main`. Shared UI in `src/components/<Name>/` follows the same layout as a module (component + CSS together, `constants`/`helpers`/`hooks`/`types`/`tests` only when needed).
- Query persist: `@tanstack/react-query` + `@tanstack/react-query-persist-client` + `idb-keyval`. Query helpers live in `src/helpers/query/` (`constants.ts`, `createQueryClient.ts`, `createQueryPersister.ts`). Provider is a route layout (`QueryPersistenceProvider` + `Outlet`) under `RequireAuth`, not around `App`. Login stays outside Query. Client via `useState(createQueryClient)`. Storage key `monetta.queryCache`. `gcTime` is `Infinity` (do not use 90d: `setTimeout` overflows at ~24.8d and GC's the restore in 1ms). Persist `maxAge` is 90 days. `staleTime` is 1 hour; `retry` is 1. `onSuccess` restore calls `invalidateQueries()` so a cold start refetches Firefly. Logout should call `queryClient.clear()` plus `removeClient()` (US-039). Do not add Query to `openapi-ts` / `src/api`.
- Wallet currency: helpers in `src/helpers/currency/` (`types.ts`, `fetchPrimaryCurrency.ts`, `fetchExchangeRates.ts`, `convertToPrimary.ts`, `formatWalletAmount.ts`). Query keys `PRIMARY_CURRENCY_QUERY_KEY` / `EXCHANGE_RATES_QUERY_KEY`. Tests in `src/helpers/tests/`. Use `getPrimaryCurrency`, not `primaryCurrency` (that POST makes a currency primary). `listCurrencyExchangeRates` is paged (`limit` 50); keep latest `date` per `from+to` and uppercase codes. Empty rates is valid. `convertToPrimary` is pure: same code → amount; direct `from→primary`; else reverse `1/rate`; no pair → `null` (no 1:1, no third currency, no rounding). `formatWalletAmount` uses `toFixed(decimalPlaces)` for parameters-bar / Analytics totals. Account cards stay on `formatAccountAmount` without rounding.
- Budget accounts: types in `src/modules/budget/types/budgetAccount.ts` (`AccountType` INCOME|CURRENT|EXPENSE, `isDebt`, currency, debt fields). `icon`/`color` are `string | null` — no Wallet/`#4C6EF5` in the model; UI fallback is US-010/US-016. Map Firefly with `Pick<AccountRead, 'id' | 'attributes'>`: revenue→INCOME, asset→CURRENT, expense→EXPENSE, liability/liabilities→EXPENSE+debt; skip `active: false`, empty id/name, other Firefly types. Buckets keyed by `AccountType`; order preference wire key is `type.toLowerCase()` (`monetta.accountOrder.income`). Preferences: paged `listPreference` and PUT `updatePreference`. Appearance is a JSON string; `PolymorphicProperty` is not an object. Do not write appearance while mapping.
- Firefly paging: `collectFireflyPages` in `src/helpers/collectFireflyPages.ts`. Tests in `src/helpers/tests/`. `page` from 1; caller sets `limit` inside `fetchPage`. Missing payload/`data` throws `missingError`; empty `data: []` is valid. Non-Error SDK throws become `Error(missingError)`. Used by `fetchAccountPreferences`, `fetchExchangeRates`, `fetchBudgetAccounts`. Keep `PREFERENCES_PAGE_LIMIT`, `EXCHANGE_RATES_PAGE_LIMIT`, and `ACCOUNTS_PAGE_LIMIT` as separate 50s.
- Budget query: `useBudgetAccounts(month)` is a thin `useQuery` over `fetchBudgetAccounts(date)`. Prefix `BUDGET_ACCOUNTS_QUERY_KEY` is `['budget', 'accounts']`; the live key is `['budget', 'accounts', date]` so `invalidateQueries` still matches. `date` is `fireflyBalanceDate`: current month → today, past month → last day, future → today. Still do not pass `type` to `listAccount`. Do not remap `BudgetAccountsByBlock` to `income`/`current`/`expense` and do not default `data` with empty arrays — `data === undefined` means no cache yet. Budget keeps `ParametersBar` when `!data`; loading/error status replaces the account blocks only. `emptyAccountsByType` stays private in `toBudgetAccounts`. No `placeholderData`/`initialData`. `invalidateQueries` after mutations is US-017+. Live cache→refetch needs a Firefly PAT.
- Budget chrome: `Budget.tsx` + `Budget.module.css` fill `AppLayout` `main` (`height: 100%`, column, `overflow: hidden`). `AppLayout` `main` is `overflow: hidden` so pages own scroll (History/Analytics add theirs later). `ParametersBar` has `MonthPickerInput` (`month` + `onMonthChange`; `maxDate` today; `valueFormat` `MMM YYYY`; ignore `null`) and read-only Income/Expenses/Balance via `useBudgetMonthTotals`. Edit is still a stub (US-027). Month state lives in `Budget` (`useState`, not localStorage). `AccountBlock` is pager only, no visible heading (`aria-label` via `budget.income` / `budget.current` / `budget.expense`). Income/Current `flex-shrink: 0`; Expense `flex: 1` so it takes leftover space above the footer. Page gap between blocks is `16px`. Bar labels: `budget.parameters.*` (`expenses` vs block `budget.expense`). Do not duplicate the footer.
- Budget month: helpers in `helpers/budgetMonth.ts`. Clock is only `todayIso()`. Formulas take `MonthToday` (`startOfMonth`, `fireflyBalanceDate`, `monthRange`, `defaultTransactionDate`). React files do not import dayjs. `@mantine/dates/styles.css` is imported in `App.tsx` right after core styles. Mantine 9 values are `YYYY-MM-DD` strings. `defaultTransactionDate` is for US-024 (today if current Budget month, else first of month) — do not wire it into transaction UI yet. `monthRange` is `{ start: startOfMonth, end: fireflyBalanceDate }` for insight totals.
- Budget month totals: Income/Expenses from `insightIncomeTotal` / `insightExpenseTotal` (`result.data` is a raw `InsightTotal` array, not JSON:API). `accounts[]` omitted. `Math.abs` on insight `difference` (Firefly may send expenses negative). Balance is the sum of Current (asset) `balance` on `fireflyBalanceDate`, not Income − Expenses and not `getBasicSummary`. Convert each currency with `convertToPrimary`; missing rate → `null` → `'—'` (no partial sum). Empty insights/Current → `0.00`. Query keys: `['budget', 'insights', start, end]`, plus shared currency keys. `useBudgetMonthTotals` reuses `useBudgetAccounts` cache. Mutations later should also invalidate `BUDGET_INSIGHTS_QUERY_KEY`. Do not use Firefly `pc_current_balance`.
- Budget cards: `AccountItem` + `AddAccountButton`. UI fallbacks `DEFAULT_ACCOUNT_ICON` (`Wallet`) and `DEFAULT_ACCOUNT_COLOR` (`#4C6EF5`) — do not bake them into the mapper. Account icons are a closed catalog in `components/accountIcons.ts` (`ACCOUNT_ICONS` + `resolveAccountIcon`); preference key is the catalog name (`Wallet`), not `WalletIcon`. Unknown/missing names fall back to Wallet. Helpers must not import Phosphor. Picker iterates `ACCOUNT_ICONS` (50 Phosphor names, named imports only). `AccountIcon` is a static wrapper (icon as prop) for `static-components`. One `AccountPageGrid` for all blocks; height via `--account-card-min-height` (`ACCOUNT_CARD_MIN_HEIGHT_DEFAULT` 6rem, Expense `ACCOUNT_CARD_MIN_HEIGHT_EXPENSE` 7.5rem) so cards and Add match. Do not pass `type` into Add until US-016. Debt: `debtAmount` red, `paidAmount` green, no `balance`. `formatAccountAmount` is number + symbol (else code), no `convertToPrimary`. `budget.addAccount` i18n. Cards are not buttons (US-018).
- Account icon picker: `AccountIconPicker` in `src/modules/budget/components/AccountIconPicker/` (Budget-only, not `src/components`). Controlled: `opened` + `onClose` + `value: AccountIconName` + `onChange` (commit only on cell click) + required `color` (CSS `--account-icon-picker-color` for selected glyph/border/fill). Overlay/Escape call `onClose` only. Add currently passes `DEFAULT_ACCOUNT_COLOR`; US-016 passes the form color. Modal content is height-capped (`min(28rem, viewport)`) with `overflow: auto` on the body so the grid scrolls. Catalog guard is `isAccountIconName` / `toAccountIconName` (trim + Wallet fallback); `resolveAccountIcon` is `ACCOUNT_ICONS[toAccountIconName(name)]`. Grid glyphs use a static `IconCell` (`icon` prop, `aria-label={name}`); do not put `useTranslation` on every cell. Temporary host is `AddAccountButton` (`useDisclosure` + local `useState`); badge shows selected icon so US-015 can be verified without Create account. Accessible name of Add stays `budget.addAccount` (`aria-haspopup` / `aria-expanded` only). US-016: remove picker from Add, restore Plus, open Create account, put **one** picker on the form icon-button (`budget.iconPicker.open`). Pager swipe does not start when `event.target.closest('button')` — do not `stopPropagation` on Add. No persist / Firefly / `AccountType` yet.
- Budget paging: one `AccountBlockPager` for Income, Current, and Expense (no third markup, no Embla/Mantine Carousel). Layout per block is `ACCOUNT_BLOCK_PAGER` (`fillHeight`, CSS `minHeight`, `minCardHeightPx`) spread into the pager — the hook does not know `AccountType` or Expense. `fillHeight` means stretch the viewport to measure leftover height and use `rowCount`; without it rows stay 1 (US-011). Expense rows are compact at card min-height (`grid-template-rows: auto`); leftover height is not distributed with `1fr`. No visible Income/Current/Expense headings; `aria-label` on the section. `useElementSize` on the viewport reads width and height. `useMediaQuery` with `961px`, not Mantine `md`. Paging math in `helpers/accountBlockPaging.ts`: `pageCount`, `slicePage`, `columnCount`, `rowCount` (height `<= 0` → 1 row, default gap `ACCOUNT_GRID_ROW_GAP_PX` 0), `nextPageIndex` (wrap last→0), `prevPageIndex` (wrap 0→last). Column gap stays `--mantine-spacing-xs` / `ACCOUNT_GRID_GAP_PX` (10); row gap is 0 — card padding (`--mantine-spacing-xs`) already separates row content. Item count is `accounts.length + 1` (Add last). `useAccountBlockPager` returns `columns`, `pageSize`, `totalPages`, `pageIndex`, `next`/`prev`/`goToPage` (derived clamp). Viewport slices by `pageSize` and loops by `totalPages` — do not recompute `columns * rows` there. Carousel: `AccountBlockViewport` (`usePageSwipe`, `pageSwipe.ts`), three slides (`prev | current | next`). Loop when `totalPages > 1`; rubber-band only on one page. Swipe tokens (`PAGE_SWIPE_*`) in module `constants.ts`; `PageSwipeDirection` in `types/pageSwipeDirection.ts`. Mobile `<961px` is 4 columns; unmeasured width (`<= 0`) stays 4. Arrows only desktop and `totalPages > 1`. Dots always. `AccountPageItem` in `types/accountPageItem.ts`; `toAccountPageItems` next to `AccountBlock`. `useBudgetAccounts` unchanged. US-027 can turn off swipe in the viewport; US-028 can keep a card in-hand at the edge without touching Query hooks.
